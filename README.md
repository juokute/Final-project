# Lėšų rinkimo platforma

Web aplikacija, leidžianti vartotojams dalintis asmeninėmis istorijomis ir rinkti lėšas.

## Funkcionalumas

- Vartotojų registracija ir prisijungimas
- Rolių sistema: administratorius ir vartotojas
- Istorijų kūrimas, redagavimas ir trynimas (CRUD)
- Nuotraukų įkėlimas prie istorijų
- Hash-tagų sistema istorijų žymėjimui
- Reakcijos (patiktukai) į kitų vartotojų istorijas
- Moderavimo srautas: istorija skelbiama tik po administratoriaus patvirtinimo

## Technologijos

- **Back-end:** PHP, Laravel
- **Front-end:** Blade, JavaScript, Tailwind CSS
- **Duomenų bazė:** MySQL
- **Versijų valdymas:** Git / GitHub

## Apie projektą

Projektas sukurtas kaip baigiamasis darbas Baltijos technologijų instituto Programavimo programoje.
